Small text is the hold action; the corner legend is what Shift + that key types. Dashed keys pass through to the layer below. / is Fn + the key after P and ? is Fn + comma. Del is Nav + Bksp, with = beside it. Both Shifts stay Shift on Nav. Hold either Space for Nav; while one Space is held, the other is Backspace. Media is on Fn: Enter ⏯, Bksp ⏭, Right Shift Vol+, right ⌃ Vol−, right ⌘ Mute. Hold Fn + either Space for System: USB and Bluetooth 1–3. Brackets mirror under the index and middle fingers: [ ] on R U, { } on D K, ( ) on F J. Striped keys were set in firmware, so ZMK Studio can't show or change them. (ZMK layer 2 is no longer used.)
